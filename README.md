# 녹내장 안압 시뮬레이터

눈 속 물(방수)이 만들어지고 빠져나가는 길과, 그 균형이 깨질 때 시신경이 어떻게 상하는지 눈 애니메이션으로 보여 주는 교육용 웹 페이지입니다. 녹내장 약이 붙는 자리와, 감기약 같은 다른 약이 어떤 녹내장에서 왜 위험한지도 같은 그림에서 켜 볼 수 있습니다.

**바로 열기:** https://sihuny227-rgb.github.io/glaucoma-simulator/

## 무엇을 볼 수 있나

- **눈 앞부분 단면**: 모양체에서 만들어진 방수 알갱이가 후방 → 동공 → 전방을 지나 섬유주 경로(섬유주 → 슐렘관 → 상공막정맥)와 포도막공막 경로로 빠져나가는 모습
- **눈 상태 네 가지**
  - 정상 눈: 방수 한 방울을 따라가며 생성·순환·배출 단계를 표시
  - 개방각녹내장(POAG): 각은 열려 있는데 섬유주 배출이 막혀 안압이 오름
  - 정상안압녹내장(NTG): 안압은 정상 범위인데 시신경이 약해 손상이 진행
  - 폐쇄각녹내장(PACG): 장면 버튼으로 평소(좁은 각), 급성 발작, 만성 폐쇄각(주변홍채앞유착, PAS)을 바로 볼 수 있음
- **시신경유두 단면·안저·시야**: 안압이 사상판을 미는 힘, 축삭수송 정체, 줄어드는 신경섬유, 커지는 함몰(C/D), 코쪽 계단에서 터널 시야까지 진행하는 시야 결손. 이미 잃은 축삭은 안압을 낮춰도 돌아오지 않음
- **녹내장 약 9가지**: 프로스타글란딘 유사체, β차단제, α2 작용제, CA 억제제(점안·경구), 필로카르핀, ROCK 억제제, 만니톨, 레이저 홍채절개술. 켜면 수용체 배지와 Goldmann 식(F · U · C · Pv), 안압이 바로 바뀜
- **함께 먹는 다른 약·상황 9가지**: 종합감기약, 코막힘약, 1세대 항히스타민제, 멀미 패치·진경제, 항콜린 처방약, 산동 점안제, 어두운 곳, 스테로이드, 토피라메이트. 같은 약이라도 좁은 각에서는 급성 발작, 개방각에서는 동공만 커지는 차이를 보여 줌
- **급성 발작 응급 처치 순서**: 방아쇠 끄기 → 방수 생성 줄이기 → 만니톨 → 안압 40 아래에서 필로카르핀 → 레이저 홍채절개술. 켤 때마다 체크됨
- **24시간 안압 곡선**: PGA를 저녁 9시와 아침 9시에 넣을 때의 차이, 밤에 효과가 작은 β차단제
- 표적 정리표, 약 지도(기전·하강률·부작용과 이유·확인할 것), 녹내장 종류별 위험 약 표, 점안 교육과 PGA를 저녁에 넣는 이유
- 저녁에 넣는 약에는 달 모양 표시: 라타노프로스트 등 PGA, 네타르수딜

## 사용 방법

설치할 것이 없습니다. 위 주소로 열거나 `index.html`을 브라우저로 열면 됩니다.

## 근거와 주의

「녹내장·백내장 병태생리 및 약물치료 완전정리」(2026-11-12), AAO Primary Open-Angle Glaucoma PPP, NICE NG81을 바탕으로 정리했습니다.

교육용 모식도입니다. 안압·방수량·축삭 손실 속도·유착 비율·24시간 곡선은 개념을 보여 주기 위한 단순 모델 값이며 실제 환자 평가나 처방을 대신하지 않습니다. 성분별 용법·금기·국내 허가사항은 개별 제품 설명서(의약품안전나라)와 처방을 확인하세요.
